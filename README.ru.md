# lg-dual-mode

Переключение **Dual-Mode** монитора LG UltraGear 45GX950A из Linux.

Монитор умеет менять физическую активную область панели: полная ширина
(5120×2160@165, 104×44 см) либо вырезанный по центру прямоугольник 16:9 37″
(3840×2160@165, 78×44 см). Штатно это делается только через экранное меню или
фирменную утилиту LG Switch, которая существует лишь под Windows и macOS.

```
lg-dual-mode status     текущий режим
lg-dual-mode wide       полная ширина
lg-dual-mode 16:9       16:9 37"
lg-dual-mode toggle     переключить на другой
```

## Как это работает

Команда уходит по DDC/CI поверх i2c видеокабеля — своя реализация, без `ddcutil`.

| | |
|---|---|
| VCP-код | `0xB1` (`eMCCS_OPCODE_MONITOR_DUAL_MODE`) |
| Значение | `(группа << 8) \| индекс` |
| Группа | `0x22` — Dual-Mode выключен, `0x21` — включён |

Индексы группы `0x22`: `0` полная ширина, `1` — 16:9 37″, `2` — 16:9 24.5″,
`3` — 16:9, `4` — 24.5″.
Индексы группы `0x21`: `0` полная ширина, `1` — 21:9 39″, `2` — 21:9 34″,
`3` — 16:9 37″, `4` — 16:9 27″, `5` — 16:9 24″.

Код write-only и не заявлен в capabilities монитора, поэтому `ddcutil` требует
для него `--permit-unknown-feature`, а сравнение читаемых VCP-значений до и после
переключения никакой разницы не показывает.

Текущий режим определяется по product code в EDID: `40605` — полная ширина,
`40616` — 16:9 37″. Шина i2c ищется перебором `/dev/i2c-*` со сверкой EDID, так
что смена видеовыхода ничего не ломает.

## Откуда взялись опкоды

Установщик LG Switch (InstallShield) распакован через
`wine LGSwitch_7.60.exe /extract_all:<dir>`, затем `unshield`. Приложение
оказалось на .NET, сборки `ModeSwitchModule.dll` и `SwitchAppModel.dll`
декомпилированы `ilspycmd`. Опкоды лежат в enum `MonitorOpcode.T_E_OPCODE`.


USB-HID `043e:9a8a` («LG Monitor Controls», появляется при подключении USB-C
upstream) к переключению отношения не имеет — им пользуются только модули
обновления прошивки.

## Установка

```sh
cargo build --release
sudo install -m 755 target/release/lg-dual-mode /usr/local/bin/
sudo install -m 644 udev/60-lg-dual-mode-i2c.rules /etc/udev/rules.d/
sudo usermod -aG i2c "$USER"
```

Членство в группе подхватывается только после перелогина. `status` работает и
без него — он читает EDID из sysfs.

## Ограничения

- Переключение меняет EDID целиком: монитор представляется другим устройством,
  и композитор заново применяет конфигурацию дисплея.
- На HDMI это ломало линк на драйвере nvidia 595.84
  (`HDMI FRL link training failed`, сигнал не возвращался). На DisplayPort
  проблемы нет — FRL там не используется.
- Аппаратная кнопка Dual-Mode на самом мониторе для пары «полная ширина ↔
  16:9 37″» не годится: она помнит только режимы группы «Вкл».
